# 接口规范与收银台设计文档 (Cashier & Webhook Specification)

## 1. 计费模型与收费标准
- **收费标准**: **¥600.00 元人民币 / 店铺** (按 Wildberries 店铺计费)；
- **发码规则**: 用户支付宝扫码支付 600 元，系统秒级自动签发 1 个专属单店商业授权码；
- **店铺隔离**: 单窗口 1:1 店铺互斥锁定，从物理根源杜绝商品串店与库存错乱；
- **授权有效期**: 永久商业授权 (默认签发 3650 天或 2099 年)，含 1 次安全换店配额。

---

## 2. 收银台界面 (`/pay`)
- **设计风格**: 现代暗黑极简科技风 (Dark Minimalist Theme)；
- **核心输入项**:
  1. 💻 **目标电脑机器码 (`mid`)** `*`：用户在 Antigravity 聊天窗口输入「`获取机器码`」获取；
  2. 🏪 **绑定 Wildberries 店铺名称 / 简称 (`store_name`)** `*`：例如「我的WB一店」；
  3. 👤 **客户联系人 / 手机号 (`name`)**：选填；
  4. 📦 **店铺授权套餐**:
     - **单店商业授权 (1 家店)**: `¥600.00` (默认标准)；
     - **双店进阶套餐 (2 家店)**: `¥1200.00`；
     - **三店旗舰套餐 (3 家店)**: `¥1800.00`。
- **支付交互**:
  1. 点击「支付宝一键安全支付 (¥600.00) · 立即发码」；
  2. 前端请求 `POST /api/pay/create-order`，重定向至支付宝收银台；
  3. 支付完成后支付宝跳回 `/pay?order_id=WB_ORD_...`，前端 2 秒轮询订单状态；
  4. 识别到 `PAID` 状态后，弹出授权码并支持「一键复制」，展示 Antigravity 激活指引。

## 3. 订单创建接口 (`POST /api/pay/create-order`)
- **请求体**:
  ```json
  {
    "mid": "MID-ABCD-1234-5678-EF01",
    "store_name": "我的WB第一分店",
    "name": "张先生",
    "plan_id": "single_store"
  }
  ```
- **响应体**:
  ```json
  {
    "ok": true,
    "order_id": "WB_ORD_20260916124021_JCR7V",
    "amount": "600.00",
    "plan_name": "单店商业授权 (1 家店铺)",
    "store_name": "我的WB第一分店",
    "pay_url": "https://openapi.alipay.com/gateway.do?app_id=2021007100687379&method=alipay.trade.page.pay..."
  }
  ```

## 4. 支付宝异步通知 Webhook (`POST /api/pay/alipay-callback`)
- **处理逻辑**:
  1. 接收 `application/x-www-form-urlencoded` 表单数据；
  2. 提取除 `sign` 与 `sign_type` 外的所有参数，按字典序升序排列待签名串；
  3. 使用支付宝官方公钥进行 RSA-SHA256 验签；
  4. 验证通过后，读取 `passback_params` 中的机器码、店铺简称与客户名；
  5. 使用 RSA-PSS 2048-bit 私钥签发 `LIC-RSA-...` 专属商业授权码；
  6. 保存授权记录到 KV 并将订单标记为 `PAID`；
  7. 响应纯文本 `success` 告知支付宝。

---

## 5. 管理控制台 (`GET /admin?key=YOUR_SECRET`)
- **功能**:
  - 店铺授权总量、在线有效店铺数、支付宝成交订单数、累计销售金额实时统计；
  - 授权管理表格：展示客户名、店铺简称、机器码、授权码、到期时间、使用量，支持一键「在线封禁」、「解封」、「续期+365天」；
  - 财务订单表格：商户订单号、授权套餐、店铺简称、实付金额 (¥600/店)、客户名、机器码、支付宝流水号、支付时间、状态。
